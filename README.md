学生の予定管理アプリ

#<概要>
学生が日々の予定を立てやすくし、朝の準備を効率化することを目的としたアプリです。
朝の準備にかかる時間を短縮し、少しでも長く布団の中で過ごせるようにすることで、忙しい学生の朝をより快適にすることを目指しています。

#<主な機能>
時間割＆持ち物の自動表示
教科を選ぶだけで持ち物を自動でリスト化
「明日の準備」ワンタップ切り替え
置き弁に登録したのは持ち物に表示しない
曜日ごとの部活管理
天気予報＆雨傘アラート
テストのカウントダウン＆自動通知
画面の色を自由に変えれる

#<使用技術>
使用技術
HTML：アプリの構造や画面の要素を作成
CSS：画面のデザインやレイアウトを調整
JavaScript（JS）：アプリの機能や動作を実装

#<今後の展望>
対象ユーザーの拡大： 現在は高校生を対象としているが、今後は大学生・中学生・小学生にも対象を広げ、それぞれの生活スタイルに合った予定管理を実現する。
実際の高校現場への導入： 実際の高校でアプリを導入し、生徒に利用してもらうことで、使いやすさや効果を検証し、改善を重ねる。
収益化： 利用者の利便性を損なわない方法で収益化を目指し、アプリの継続的な運営と機能の充実につなげる。
